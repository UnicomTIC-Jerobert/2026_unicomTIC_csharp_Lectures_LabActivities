
## 🎓 Daily Quiz (End of Day)

**Instructions:** Choose the best answer for each question.

1.  In OOP, what is a "Class"?
    a) An instance of an object.
    b) A blueprint or template for creating objects.
    c) A method that belongs to an object.
    d) A variable that holds data.

2.  In OOP, what is an "Object"?
    a) The blueprint for a data type.
    b) A keyword used to define a method.
    c) A specific instance created from a class.
    d) A static method.

3.  What keyword is used to create an instance of a class?
    a) `create`
    b) `instance`
    c) `new`
    d) `object`

4.  In `public class Car { public string Color { get; set; } }`, what is `Color`?
    a) A method
    b) A class
    c) A property
    d) A constructor

5.  What is the name of the special method that is called when an object is created?
    a) `Main`
    b) `Initializer`
    c) `Constructor`
    d) `Start`

6.  A constructor method must...
    a) Have the same name as the class and a `void` return type.
    b) Have the name `Create` and return the class type.
    c) Have the same name as the class and no return type.
    d) Be named `Main`.

7.  The process of creating an object from a class is called...
    a) Declaration
    b) Instantiation
    c) Compilation
    d) Refactoring

8.  What is the primary purpose of a constructor?
    a) To destroy an object.
    b) To initialize an object's properties to a valid starting state.
    c) To define the behavior of an object.
    d) To display information about an object.

9.  If you have a class `Dog` with a method `public void Bark()`, and an object `Dog myDog = new Dog();`, how do you call the method?
    a) `Dog.Bark();`
    b) `myDog.Bark();`
    c) `Bark(myDog);`
    d) `new Bark.myDog();`

10. The concept of bundling data (properties) and behavior (methods) together is called...
    a) Inheritance
    b) Polymorphism
    c) Encapsulation
    d) Abstraction

11. A class named `Person` is defined. How do you create an object of this class named `p1`?
    a) `Person p1 = Person();`
    b) `Person p1 = new Person();`
    c) `new Person = p1;`
    d) `p1 = new Person;`

12. If a property is declared as `private`, it can be accessed...
    a) From anywhere in the program.
    b) From any method in the same project.
    c) Only from within the same class.
    d) Only by a constructor.

13. In a WPF application, where is the ideal place to create and initialize the main data objects that the window will use?
    a) In a `Button_Click` event.
    b) In the `MainWindow` constructor.
    c) In the XAML file.
    d) In a separate `Program.cs` file.

14. What is the benefit of using an object to hold a student's data (`Name`, `ID`) instead of separate variables?
    a) It uses less memory.
    b) The data is logically grouped together, making the code cleaner and more manageable.
    c) It runs faster.
    d) It is the only way to store strings.

15. Given `public class Cat { public Cat(string name) { ... } }`, which line of code is valid?
    a) `Cat myCat = new Cat();`
    b) `Cat myCat = new Cat("Whiskers");`
    c) `Cat myCat = "Whiskers";`
    d) `new Cat(myCat, "Whiskers");`

16. The `this` keyword inside a class method refers to...
    a) The class itself (the blueprint).
    b) The specific object instance that the method was called on.
    c) The `Main` method.
    d) The parent class.

17. In the line `Car myCar = new Car();`, `myCar` is the...
    a) Class
    b) Object/Instance variable
    c) Constructor
    d) Property

18. A class defines a new...
    a) Method
    b) Variable
    c) Data Type
    d) Namespace

19. In WPF, if you want to display the `Title` property of a `Book` object named `currentBook` in a `TextBlock` named `TitleBlock`, you would write:
    a) `TitleBlock.Text = currentBook.Title;`
    b) `currentBook.Title = TitleBlock.Text;`
    c) `TitleBlock.Text = Book.Title;`
    d) `Text(TitleBlock) = currentBook.Title;`

20. What is the fundamental problem that Object-Oriented Programming (OOP) aims to solve?
    a) Code that runs too slowly.
    b) The separation of related data and the behaviors that act upon that data.
    c) The inability to get user input.
    d) The difficulty of writing loops.

  2. **c)** A specific instance created from a class.
  3. **c)** `new`
  4. **c)** A property
  5. **c)** `Constructor`
  6. **c)** Have the same name as the class and no return type.
  7. **b)** Instantiation
  8. **b)** To initialize an object's properties to a valid starting state.
  9. **b)** `myDog.Bark();`
  10. **c)** Encapsulation
  11. **b)** `Person p1 = new Person();`
  12. **c)** Only from within the same class.
  13. **b)** In the `MainWindow` constructor.
  14. **b)** The data is logically grouped together, making the code cleaner and more manageable.
  15. **b)** `Cat myCat = new Cat("Whiskers");` (because the constructor requires a string argument).
  16. **b)** The specific object instance that the method was called on.
  17. **b)** Object/Instance variable
  18. **c)** Data Type
  19. **a)** `TitleBlock.Text = currentBook.Title;`
  20. **b)** The separation of related data and the behaviors that act upon that data.
