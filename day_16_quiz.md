## 🎓 Daily Quiz (End of Day)

**Instructions:** Choose the best answer for each question.

1.  What does SQL stand for?
    a) Structured Query Language
    b) Simple Query Logic
    c) Standardized Question Language
    d) System Query Library

2.  In a relational database, data is stored in...
    a) Files and Folders
    b) Objects and Classes
    c) Tables, Columns, and Rows
    d) Key-Value Pairs

3.  What is the main purpose of a `PRIMARY KEY`?
    a) To sort the table by default.
    b) To uniquely identify every row in a table.
    c) To link to other databases.
    d) To store the most important piece of data.

4.  Which SQL command is used to create a new table?
    a) `NEW TABLE`
    b) `ADD TABLE`
    c) `CREATE TABLE`
    d) `MAKE TABLE`

5.  Which SQL command is used to retrieve data from a database?
    a) `GET`
    b) `FETCH`
    c) `QUERY`
    d) `SELECT`

6.  The `*` in `SELECT * FROM Users` means...
    a) Select the first row.
    b) Select all rows.
    c) Select all columns.
    d) Select the primary key.

7.  Which clause is used to filter rows in a `SELECT` statement?
    a) `FILTER BY`
    b) `HAVING`
    c) `WHERE`
    d) `CONDITION`

8.  To add a new row to a table, you use which command?
    a) `ADD ROW`
    b) `CREATE ROW`
    c) `INSERT INTO`
    d) `UPDATE`

9.  What is wrong with the following command? `UPDATE Products SET Price = 50;`
    a) Nothing is wrong.
    b) It is missing the `INTO` clause.
    c) It is missing a `WHERE` clause and will update **every** row in the table.
    d) `SET` is not a valid SQL keyword.

10. Which command is used to sort the results of a query?
    a) `SORT BY`
    b) `ARRANGE BY`
    c) `ORDER BY`
    d) `GROUP BY`

11. What is SQLite?
    a) A large, server-based database system like SQL Server.
    b) A programming language.
    c) A lightweight, file-based database engine.
    d) A text editor for SQL.

12. The `NOT NULL` constraint on a column means...
    a) The column must be a number.
    b) The column cannot contain text.
    c) The column must have a value; it cannot be empty.
    d) The column is a primary key.

13. Which command permanently removes a row from a table?
    a) `REMOVE`
    b) `DROP`
    c) `CLEAR`
    d) `DELETE`

14. The data type for storing text in SQLite is typically...
    a) `STRING`
    b) `VARCHAR`
    c) `TEXT`
    d) `CHAR`

15. To select all products whose price is greater than 10 AND less than 50, you would write:
    a) `WHERE Price > 10 AND Price < 50`
    b) `WHERE Price BETWEEN 10, 50`
    c) `WHERE Price > 10 OR Price < 50`
    d) `WHERE Price > 10 && Price < 50`

16. What does `AUTOINCREMENT` do for a primary key?
    a) It automatically generates a new, unique integer for each new row.
    b) It increases the value of the key by 1 every second.
    c) It is not a valid SQL keyword.
    d) It encrypts the key.

17. To get only the `Name` and `Price` columns from a `Products` table, you would write:
    a) `SELECT Name, Price FROM Products`
    b) `SELECT Products(Name, Price)`
    c) `SELECT * FROM Products WHERE Name, Price`
    d) `GET Name, Price FROM Products`

18. What is the difference between `DELETE` and `DROP TABLE`?
    a) `DELETE` removes rows; `DROP TABLE` removes the entire table structure.
    b) They are the same.
    c) `DELETE` is temporary; `DROP TABLE` is permanent.
    d) `DELETE` removes one row; `DROP TABLE` removes all rows.

19. The command `ORDER BY Name DESC` will sort...
    a) By name, A to Z.
    b) By name, Z to A.
    c) By name, grouping similar names together.
    d) By the length of the name.

20. What is data persistence?
    a) The process of writing efficient SQL queries.
    b) The ability of data to outlive the execution of a program.
    c) The speed at which a database can retrieve data.
    d) A design pattern for organizing code.
