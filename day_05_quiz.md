## 🎓 Weekly Review Quiz (End of Day)

**Instructions:** This quiz covers all topics from Week 1. Choose the best answer.

1.  Which data type would you use to store a user's name?
    a) `int` b) `double` c) `string` d) `bool`
2.  The `Console.ReadLine()` method returns what data type?
    a) `int` b) `double` c) `string` d) `bool`
3.  What is the purpose of the `int.Parse()` method?
    a) To convert an integer into a string.
    b) To check if a variable is an integer.
    c) To convert a string representation of a number into an integer.
    d) To format an integer with commas.
4.  Which operator checks for exact equality?
    a) `!=` b) `=` c) `==` d) `<>`
5.  Which loop structure is best suited for an interactive menu that must be displayed at least once?
    a) `for` b) `while` c) `do-while` d) `if`
6.  The `&&` logical operator returns true only if...
    a) One of the conditions is true.
    b) Both of the conditions are true.
    c) Both of the conditions are false.
    d) One of the conditions is false.
7.  What is the final value of `x`? `for (int i = 0; i <= 3; i++) { x = i; }`
    a) 2 b) 3 c) 4 d) The code has an error.
8.  The `void` keyword in a method signature indicates that the method...
    a) Has an error.
    b) Does not return a value.
    c) Returns a `null` value.
    d) Can accept any type of parameter.
9.  What is the term for the variables declared in a method's signature (e.g., `int number` in `void MyMethod(int number)`)?
    a) Arguments b) Globals c) Locals d) Parameters
10. The process of extracting code into its own method to improve organization is called...
    a) Compiling b) Debugging c) Declaring d) Refactoring
11. Which statement immediately exits the current loop?
    a) `continue` b) `stop` c) `break` d) `exit`
12. A variable declared inside a `for` loop can be accessed...
    a) Anywhere in the program.
    b) Only inside that `for` loop.
    c) Anywhere inside the method containing the loop.
    d) Only in the line where it is declared.
13. In WPF, what language is used to define the UI layout?
    a) C# b) CSS c) XAML d) HTML
14. What is the output of this code? `Console.WriteLine(10 / 4);`
    a) `2.5` b) `2` c) `3` d) `2.0`
15. To disable a button named `MyButton` in WPF, you would write:
    a) `MyButton.IsEnabled = false;` b) `MyButton.IsVisible = false;` c) `MyButton.Disable();` d) `MyButton.SetState(Disabled);`
16. What is the output of `(true || false) && false`?
    a) `true` b) `false` c) The code is invalid.
17. A method signature is defined as `public double GetAverage(int a, int b)`. Which of the following is a valid call?
    a) `GetAverage(5.0, 10.0)` b) `int result = GetAverage(5, 10)` c) `double result = GetAverage(5, 10)` d) `GetAverage(5)`
18. What is the primary reason to follow the DRY (Don't Repeat Yourself) principle?
    a) To make the code run faster.
    b) To reduce the amount of code that needs to be written and maintained.
    c) To make the executable file smaller.
    d) To use less memory.
19. A `while` loop checks its condition...
    a) Before each iteration. b) After each iteration. c) Only once at the start. d) Never.
20. The main goal of "Problem Decomposition" in programming is to...
    a) Write the entire program in a single file.
    b) Break a large problem down into smaller, manageable sub-problems.
    c) Choose the best variable names.
    d) Convert the code into binary.
