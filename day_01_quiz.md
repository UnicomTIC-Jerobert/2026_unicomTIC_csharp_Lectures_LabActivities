## 🎓 Daily Quiz (End of Day)

**Instructions:** Choose the best answer for each question to test your understanding of today's topics.

**1. Which statement best describes C#?**
    a) A markup language for designing user interfaces.
    b) A runtime environment for executing code.
    c) A programming language used to give instructions to the .NET framework.
    d) A type of database.

**2. To get a user's typed input in a Console application, you would use:**
    a) `MessageBox.Show()`
    b) `Console.ReadLine()`
    c) `TextBox.Text`
    d) `Console.Write()`

**3. What is the correct data type for storing a value like `15.99`?**
    a) `int`
    b) `string`
    c) `bool`
    d) `double`

**4. The code `int.Parse("123.45")` will result in:**
    a) The integer `123`
    b) The double `123.45`
    c) An error at runtime.
    d) The string `"123.45"`

**5. In WPF, what is the primary purpose of XAML?**
    a) To perform mathematical calculations.
    b) To define the structure and appearance of the user interface.
    c) To store user data permanently.
    d) To handle button click events.

**6. If you have the variable `int score = 95;`, which line will convert it to a string for display?**
    a) `string text = parse(score);`
    b) `string text = score.ToString();`
    c) `string text = (string)score;`
    d) `string text = new String(score);`

**7. In C#, every complete instruction or statement must end with what character?**
    a) A period (`.`)
    b) A comma (`,`)
    c) A colon (`:`)
    d) A semicolon (`;`)

**8. If a `TextBox` in WPF is named `FirstNameBox`, how do you access its content in C#?**
    a) `FirstNameBox.Content`
    b) `FirstNameBox.Value`
    c) `FirstNameBox.Text`
    d) `GetText(FirstNameBox)`

**9. What is the result of the expression `(double)5 / 2` in C#?**
    a) `2`
    b) `3`
    c) `2.5`
    d) An error will occur.

**10. What is the main purpose of using `git` in our project?**
    a) To compile our C# code faster.
    b) To track changes in our code over time and share it.
    c) To automatically fix bugs in our code.
    d) To design the UI of our applications.

---
<details>
  <summary><strong>ANSWER KEY</strong></summary>
  
  1. **c)** A programming language used to give instructions to the .NET framework.
  2. **b)** `Console.ReadLine()`
  3. **d)** `double`
  4. **c)** An error at runtime. (`int.Parse` cannot handle decimals; `double.Parse` would work).
  5. **b)** To define the structure and appearance of the user interface.
  6. **b)** `string text = score.ToString();`
  7. **d)** A semicolon (`;`)
  8. **c)** `FirstNameBox.Text`
  9. **c)** `2.5` (Casting one of the integers to a `double` ensures floating-point division).
  10. **b)** To track changes in our code over time and share it.
</details>
